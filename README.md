
# Face Verification System

A deep learning-based face verification system that determines whether two face images belong to the same person.

## Project Objectives

- Build a Siamese CNN for face verification.
- Learn facial embeddings and similarity comparison.
- Evaluate performance under different conditions.
- Investigate robustness to masks, glasses, lighting and facial angles.
- Explore anti-spoofing to detect presentation attacks.
- Build a web application for face registration and verification.

## Planned Technologies

- Python
- PyTorch
- OpenCV
- FastAPI
- React

## Project Architecture

The system will contain three main components:

1. Face Detection
2. Face Verification
3. Anti-Spoofing

Currently setting up the development environment and project structure.
